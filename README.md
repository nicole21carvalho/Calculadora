# 🧮 Calculadora

Calculadora web feita com **HTML, CSS e JavaScript puro**, sem bibliotecas.

🔗 **[Abrir a calculadora](https://nicole21carvalho.github.io/Calculadora/)**

![Calculadora](calculadora.png)

## ✨ Funcionalidades

- ➕ Soma, subtração, multiplicação e divisão, com números decimais
- ⬅️ Apagar o último dígito e 🧹 limpar o visor
- 🟰 Mostrar o resultado da expressão digitada

## 🛠️ Tecnologias

HTML · CSS · JavaScript

## 📁 Estrutura

```
index.html   → layout da calculadora
style.css    → estilo
script.js    → lógica dos botões e do cálculo
```

## 🚀 Como executar

Abra o [site publicado](https://nicole21carvalho.github.io/Calculadora/) ou baixe o repositório e abra o `index.html` no navegador.
